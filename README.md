# A.Multi-Mod.Chinese.Localization
一个“未知伤亡（Casualties Unknown）”的a.chs.mod多模组汉化

直接把下载好的.dll文件放入游戏的"Casualties Unknown Demo\BepInEx\plugins"文件夹即可。

繁体中文使用 Python opencc-python-reimplemented s2tw 转换，未做校对

！有什么想汉化的模组或 文本错误欢迎联系我

~~！每次启动游戏，在游玩中，打开制作界面和鼠标指向物品等，第一次会小卡一下，自动建立缓存后不会小卡一下，关闭游戏后缓存清空，~~ 正在优化　8月3日：我还以为是模组优化问题，结果去掉模组加载器也是这样：打开制作界面和鼠标指向物品等第一次显示文字也会卡顿。。。切换英文完全没这个卡顿，原来是游戏代码问题啊。fallback字体unifont问题，实际上在游戏中显示任何fallback字体都会卡顿，纯拼设备性能了
